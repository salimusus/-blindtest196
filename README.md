# 🎵 Blind Test en ligne — Classique & Battle (196 chansons)

Les musiques (extraits de 30 s) se chargent automatiquement depuis la racine du dépôt.

## Mettre en ligne (GitHub Pages)
1. Pousser ce dossier sur un dépôt GitHub.
2. Settings → Pages → Branch: main / (root) → Save.
3. En ligne sous ~1 min : https://VOTRE-NOM.github.io/NOM-DEPOT/

## Modes
- Classique : buzzer + voix, premier à 5 points.
- Battle ⚔️ : 2 joueurs, choix du style en alternance, premier à 6 points.
